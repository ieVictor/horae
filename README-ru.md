# Horae — терминальный трекер учёбы

[English](README.md) | **Русский** | [中文](README-zh.md) | [Português (BR)](README-ptbr.md) | [Español](README-es.md)

Терминальный трекер учёбы, написанный на Rust с использованием Ratatui.

![экран таймера horae](assets/tracking-your-time.png)

## Возможности

- **Таймер крупными цифрами** — время сессии отображается блочными символами, а итог за день показан ниже
- **Предметы** — сессии группируются по предметам; предмет по умолчанию «General» доступен всегда
- **Учебные сессии** — каждая сессия сохраняется в SQLite вместе со временем начала, окончания и длительностью
- **Задачи** — простой список дел с заголовком, описанием, приоритетом и статусом «выполнено»/«открыто»
- **Аналитика** — недельная столбчатая диаграмма часов учёбы и полная история прошлых сессий

## Горячие клавиши

### Таймер (ожидание)

| Клавиша | Действие |
|-----|--------|
| `Space` | Открыть выбор предмета и начать сессию |
| `a` | Открыть аналитику |
| `t` | Открыть задачи |
| `s` | Открыть предметы |
| `q` | Выход |

### Таймер (идёт сессия)

| Клавиша | Действие |
|-----|--------|
| `Space` | Остановить текущую сессию |
| `t` | Открыть задачи |
| `q` | Выход |

### Выбор предмета

| Клавиша | Действие |
|-----|--------|
| `j` / `↓` | Вниз |
| `k` / `↑` | Вверх |
| `Enter` | Начать сессию с выбранным предметом |
| `Esc` / `q` | Отмена |

### Аналитика / Задачи / Предметы

| Клавиша | Действие |
|-----|--------|
| `j` / `↓` | Вниз |
| `k` / `↑` | Вверх |
| `l` / `→` | Развернуть выбранный элемент |
| `h` / `←` / `Esc` | Свернуть / назад |
| `n` | Новый элемент (задачи и предметы) |
| `d` | Удалить выбранный элемент |
| `Space` | Переключить статус задачи (только задачи) |
| `q` | Выход |

## Сборка и запуск

Требуется Rust 1.88 или новее.

```sh
cargo run --release
```

База данных SQLite (`horae.db`) создаётся в текущем рабочем каталоге при первом запуске.
