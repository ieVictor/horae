# Horae —— 终端学习记录工具

[English](README.md) | [Русский](README-ru.md) | **中文** | [Português (BR)](README-ptbr.md) | [Español](README-es.md)

一个使用 Rust 和 Ratatui 构建的终端学习记录工具。

![horae 计时器界面](assets/tracking-your-time.png)

## 功能特性

- **大字号计时器** —— 使用方块字符显示本次学习时长，下方展示当日累计时间
- **科目** —— 按科目整理学习记录；始终提供默认科目 “General”
- **学习记录** —— 每次学习都会连同开始时间、结束时间和时长一起保存到 SQLite
- **任务** —— 轻量待办列表，包含标题、描述、优先级以及已完成/未完成状态
- **统计分析** —— 每周学习时长柱状图，以及完整的历史记录

## 快捷键

### 计时器（空闲）

| 按键 | 操作 |
|-----|--------|
| `Space` | 打开科目选择器并开始学习 |
| `a` | 打开统计分析 |
| `t` | 打开任务 |
| `s` | 打开科目 |
| `q` | 退出 |

### 计时器（学习中）

| 按键 | 操作 |
|-----|--------|
| `Space` | 结束当前学习 |
| `t` | 打开任务 |
| `q` | 退出 |

### 科目选择器

| 按键 | 操作 |
|-----|--------|
| `j` / `↓` | 向下移动 |
| `k` / `↑` | 向上移动 |
| `Enter` | 以选中的科目开始学习 |
| `Esc` / `q` | 取消 |

### 统计分析 / 任务 / 科目

| 按键 | 操作 |
|-----|--------|
| `j` / `↓` | 向下移动 |
| `k` / `↑` | 向上移动 |
| `l` / `→` | 展开选中项 |
| `h` / `←` / `Esc` | 收起 / 返回 |
| `n` | 新建条目（任务和科目） |
| `d` | 删除选中项 |
| `Space` | 切换任务状态（仅任务） |
| `q` | 退出 |

## 构建与运行

需要 Rust 1.88 或更高版本。

```sh
cargo run --release
```

首次运行时会在当前工作目录中创建 SQLite 数据库（`horae.db`）。
